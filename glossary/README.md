# PaliVerse glossary (Pāli, English, Greek)

The glossary used for the PaliVerse translation of the Pāli Canon, edited by Venerable Ñāṇadassana
Mahāthera. It is kept here for translation review work, as the first reference for how a Pāli term
is rendered in English and in Greek.

## File

| File | Contents |
|---|---|
| `Pali Canon Glossary 8 Fixed 20261125.xlsx` | Version 8 of the glossary, as saved on 25 November 2026. One sheet, 25,050 entries. |

Columns: `Flag`, `Old Row`, `Pali`, `English`, `Greek`, `Notes`.

- `Pali`: the headword.
- `English`: the English rendering or definition (25,029 entries).
- `Greek`: the Greek rendering (5,738 entries).
- `Flag`: 1,358 entries carry the mark `*`.

A Pāli word can have more than one row, so read all the rows of a headword.

An unchanged copy of the PaliVerse working file.
