# PTS Pali-English Dictionary (2021 proofread digital version)

A reference copy of the Pali Text Society's Pali-English Dictionary, kept here by PaliVerse for
translation review work. It is not used by the PaliVerse website.

## Files

| File | Contents |
|---|---|
| `Tabfile_PTSPED-2021.zip` | The dictionary as plain text: one entry per line (headword, tab, definition in HTML). 15,704 entries. Unzips to one UTF-8 file of about 6.4 MB. |
| `PTSPED-2021.zip` | The same dictionary in StarDict format, for dictionary programs such as GoldenDict. |

Compounds are listed inside the entry of one of their parts (for example `vassa-kamma` under `vassa`),
so search inside the definitions as well as the headwords.

## Source

Both files are unchanged copies from <https://github.com/vpnry/ptsped> (Pāḷi Roman files).
That version was converted from Buddhadust's HTML edition, proofread in 2021 and revised in accordance
with the 2015 "Reprint with corrections" by K.R. Norman, William Pruitt and Peter Jackson.
